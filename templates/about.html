About Our Project

Crop Recommendation and Plant Disease Detection System Using Machine Learning and CNN

🌾 Project Overview

Agriculture plays an important role in our daily lives and the economy. Selecting a suitable crop and identifying plant diseases at an early stage can help farmers make better farming decisions.

Our project, Crop Recommendation and Plant Disease Detection System, is a web-based agricultural support system that combines Machine Learning and Deep Learning to provide useful predictions to users.

The system contains two main modules: Crop Recommendation and Plant Disease Detection. The crop recommendation module analyzes soil and environmental parameters to suggest a suitable crop. The plant disease detection module analyzes an uploaded leaf image to predict its plant category and possible disease.

The website is developed using Python and Flask, providing a simple interface through which users can enter agricultural information, upload leaf images, and view prediction results.

🌱 Crop Recommendation

This module recommends a suitable crop based on the agricultural parameters entered by the user.

The inputs include Nitrogen (N), Phosphorus (P), Potassium (K), soil pH, rainfall and, where supported by the trained model, other environmental parameters such as temperature and humidity.

A trained Random Forest classifier analyzes the input values and predicts the crop class that best matches the learned patterns in the training dataset.

🍃 Plant Disease Detection

This module helps identify possible plant diseases from a photograph of a leaf uploaded by the user.

It uses a Convolutional Neural Network (CNN) based on the MobileNetV2 architecture. The model is trained using labeled plant leaf images.

The uploaded image is resized and preprocessed before being passed to the trained model. The model predicts the plant and disease class with the highest output score and displays the model confidence.

🧠 Machine Learning

Machine Learning enables a computer to learn patterns from data and use those patterns to make predictions on new inputs.

In this project, Random Forest is used for crop recommendation, while the trained MobileNetV2 deep learning model is used for plant disease classification.

🎯 Project Objectives

To provide an easy-to-use digital platform that supports agricultural decision-making.

The objectives are to recommend suitable crops, help users recognize possible plant diseases, present prediction results clearly, and demonstrate the practical use of Machine Learning and Deep Learning in agriculture.

💻 Technologies Used

Python Flask Scikit-learn Random Forest TensorFlow Keras CNN MobileNetV2 NumPy Pillow HTML5 CSS3 JavaScript MySQL

⚙️ How the System Works

Step 1 – Crop Recommendation: The user enters the required soil and environmental values. The trained Random Forest model processes the values and returns a recommended crop.

Step 2 – Plant Disease Detection: The user uploads a plant leaf image. The image is preprocessed and analyzed by the MobileNetV2 model to predict the plant and possible disease class.

Step 3 – Display Results: The website presents the model's prediction and, for disease detection, the model confidence score. If configured, MySQL can store prediction history for later review by an administrator.

🌍 Conclusion

This project demonstrates how Machine Learning, Deep Learning and web technologies can be combined to develop an intelligent agricultural support system. It aims to make crop recommendations and plant disease predictions more accessible through a simple website.

The predictions are intended to support farming decisions and should be considered alongside agricultural knowledge and expert advice.
